## Avin P S | Portfolio Website

Welcome to my personal portfolio website! This project showcases my skills, projects, certifications, and experiences as a Data Science student.

## Overview

This portfolio is a fully responsive website built using HTML, Tailwind CSS, and JavaScript. It features interactive sections such as:

	•	Landing Section: Introduction with name, profile image, and call-to-action buttons.
	•	Skills Section: A grid of technical skills with a clean modern layout.
	•	Projects Section: Horizontally scrollable project cards with modal popups for details.
	•	Certifications Section: A simple, card-style layout to display completed certifications.
	•	Experience Section: Timeline-ready section for professional experience.
	•	Contact Section: Direct links to my social profiles and email.

## Technologies Used
	•	HTML5 – For structure
	•	Tailwind CSS – For responsive styling
	•	JavaScript – For interactivity (project modal)
